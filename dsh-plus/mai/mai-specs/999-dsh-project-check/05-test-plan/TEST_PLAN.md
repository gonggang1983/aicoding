## 执行准备

- 首个获批实施切片先证实独立加载、发现、真实批准成功任务、拒绝标记任务、返回报告；关键能力不足停止扩展。
- 目标 Windows x64、DSH 0.2.2-rc.3 / SHA `39163dd30f703a79079e2d2446545cff3c453738`、Node 24.18.0/npm 11.16.0。执行时记录实际版本、制品摘要、代码差异、沙箱 provider/模式/enforcement；缺固定制品受阻，不静默换版。
- 实施时建立自有临时项目，含 ASCII/中文空格路径、成功/非零/延时/后代/argv/大输出/标记脚本及合成秘密。本轮未创建；不用真实秘密或未知业务脚本。
- 证据记录安全调用参数、cwd/argv、起止/退出、plan/run ID、审批展示、双报告和独立标记/进程观察；预期不由被测函数计算。故障注入单列，不能代替真实审批/取消；不保留原始秘密或日志 spill。
- 清理仅针对本次自有临时树、已识别受管进程及 overlay，先确认退出。未知残留告知，不宽泛杀进程、不提权/关沙箱；无法安全造链接则受阻。

## 待验业务用例

### TC-01：独立宿主闭环
- 关联需求：AC-12、AC-01、AC-04、AC-10。
- 前提与数据：固定宿主、独立打包插件、成功及写标记任务；安装另获授权。
- 操作步骤：装配；真实发现/预览/批准成功项；新计划拒绝标记项；取报告；卸载 overlay。
- 预期结果：不改核心即可调用；只有批准项运行，拒绝无标记；报告可读，卸载贡献消失。import/Mock 不足。
- 验证方式与证据：实际命令/制品、审批、退出、工具清单、报告和卸载对照；缺运行条件受阻。
- 清理：确认退出后移除自有 overlay/样例。

### TC-02：发现不执行与非法配置
- 关联需求：AC-01、AC-02。
- 前提与数据：含 pre/post/标记脚本；无配置/无 scripts；非法路径/JSON、重复 ID、缺脚本、非法 args、未知字段版本、超时/任务数/文件大小边界、非 npm/锁冲突。
- 操作步骤：显式及省略路径发现，空选预览；逐个请求非法输入。
- 预期结果：默认会话 cwd，无 cwd 要求路径；候选不等于授权；无自动建配置、脚本执行、安装、换目录或包管理器回退。错误定位明确，零任务非通过。
- 验证方式与证据：T-02 参数化结果、真实代表调用、独立启动/标记观察。
- 清理：移除自有样例。

### TC-03：批准绑定及重放阻断
- 关联需求：AC-04、AC-13。
- 前提与数据：有效计划；审批不可用注入；可修改合成 package/config/工具链。
- 操作步骤：核对审批路径/argv/cwd/超时/生命周期风险；批准/拒绝；伪造 approved、篡改计划、跨会话/过期/重放；批准后及任务间修改文件。
- 预期结果：仅当前真实一次批准启动；变化阻断受影响/余项，保留既有结果，重新预览；安全投影无法核对操作则阻断。不宣称锁定全部源码。
- 验证方式与证据：T-04 测试、真实审批/摘要/标记；注入不替代真实链路。
- 清理：移除合成修改。

### TC-04：串行退出与结论
- 关联需求：AC-05、AC-07、AC-08。
- 前提与数据：0、打印 success 但非零、0 三脚本；另含全成功、零选、passed+not_run/unknown、failed+unknown、缺 npm/运行依赖样例。
- 操作步骤：批准执行，引用 T-06 状态表并复核真实报告。
- 预期结果：串行按序 passed/failed/passed，非零继续、无重试；真实起止/退出/非负耗时。failed 优先，否则空集/选定未执行或未知为证据不足，否则通过；未选不覆盖。未启动 not_run，已启动非零 failed，可能启动无终态 unknown；无虚构时间/退出码或自动安装，保留非业务验收声明。
- 验证方式与证据：真实子进程观察、状态表及双报告。
- 清理：恢复隔离配置/样例。

### TC-05：超时、取消、卸载
- 关联需求：AC-06、AC-07、AC-12。
- 前提与数据：长任务/后代/排队、根退出后代存活、终态丢失注入。
- 操作步骤：超时、真实取消、运行中卸载；取消后同会话取报告；注入终止确认失败。
- 预期结果：取消/卸载停止调度；确认停止运行项 failed、排队 not_run；确认超时可按设计继续。窗口后不明为 unknown、警示残留并停止调度；根 close 不等于树结束。取消遵守 abort，安全部分报告可取，不承诺卸载后持久报告。
- 验证方式与证据：Windows 受管范围/退出、取消及报告；注入覆盖单列。
- 清理：只处理本例已识别进程，残留不明告知。

### TC-06：Git 子树摘要
- 关联需求：AC-03。
- 前提与数据：临时仓库 staged/unstaged/untracked/rename、跨子树；clean/非仓库/缺 Git/超限/特殊路径。
- 操作步骤：子项目发现及执行，独立 Git 基准比对摘要和前后索引。
- 预期结果：仅目标子树，无正文/diff/索引修改；排序/省略真实，无法计数明确未知。无 Git 只标变更缺口，不阻止任务通过，不把全部差异归因任务。
- 验证方式与证据：T-03 结果、代表报告、索引校验。
- 清理：移除自有仓库。

### TC-07：输出脱敏与安全呈现
- 关联需求：AC-09。
- 前提与数据：超预算两流、UTF-8/chunk/半记录；合成凭据、跨换行/CRLF/控制字符/重叠字面值、HTML/围栏/伪指令。
- 操作步骤：运行并核对双报告、缓存、日志及无原始 spill。
- 预期结果：持续消费不阻塞、有界且标截断；保护秘密不进返回/缓存/日志；先字面值匹配再规范化，删除不重拼秘密；不安全片段隐藏，安全展示、不执行指令，说明脱敏局限和宿主模型传输风险。
- 验证方式与证据：T-06 合成扫描/边界/渲染及真实展示；不用真实秘密。
- 清理：移除合成数据。

### TC-08：双报告、缓存、无写盘
- 关联需求：AC-10、AC-09。
- 前提与数据：四状态样例；真实执行用不写文件脚本、独立文件清单/I/O 观察。
- 操作步骤：同会话取报告并比对；跨会话、过期/淘汰/重启后取；尝试导出及额外写盘参数。
- 预期结果：同 run 两格式任务/状态/退出/截断一致；缓存安全且归属正确，失效 unavailable 不重跑；四工具无 export，额外参数拒绝，无报告/暂存文件及写盘调用。宿主保存/脚本副作用分别归因。
- 验证方式与证据：字段对照、schema、I/O 审计、文件清单；技术缓存最近 5 份/10 分钟验证。
- 清理：观察者证据与产品行为分开归档。

### TC-09：Windows 参数和宿主限制
- 关联需求：AC-11、AC-04。
- 前提与数据：中文空格路径、元字符脚本名/参数、argv/注入标记/pre/post；自由 command/env/cwd、链接逃逸、宿主拒绝。
- 操作步骤：真实执行合法样例，核对 argv/生命周期；请求非法及受限样例。
- 预期结果：目标 cwd，插件不额外 shell 解释，npm 转发无意外注入；拒绝无直接进程/路径回退或提权。partial 披露，要求 full 不接受 partial，不承诺脚本绝对只读。链接无法创建受阻。
- 验证方式与证据：Windows argv/标记/策略、T-05 结果；失败回报，不放宽条件。
- 清理：先移除自有链接再清理样例。

### TC-10：并发、重启及禁止行为
- 关联需求：AC-13。
- 前提与数据：同项目同实例已有执行/等审批，已结束 run，重启环境。
- 操作步骤：重复执行、完成后新计划、重启后查询/尝试运行；审计正常及异常调用。
- 预期结果：busy 无第二执行/隐式队列；新 run 新 ID、不混证据；重启不恢复/重跑。无自动修复/安装/提交/推送/发布/插件新增上传，不掩盖宿主或批准脚本网络行为。
- 验证方式与证据：T-04 生命周期测试、真实调用及调用审计/源码检查。
- 清理：取消自有任务并确认退出。
